# MIS file
Mission file.

## Format
Format is `.keyword [ .keyword [ ] ]`.

| keyword                | description                  | type   |
| ---------------------- | ---------------------------- | ------ |
| `.FASExxxx`            | mission identifier (x = 0-9) | node   |
| `.DATOSFICHEROSMISION` | mission files data           | node   |
| `.VOLUMENES`           | .VOL file name               | string |
| ...                    |                              |        |
