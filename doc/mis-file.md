# MIS file
Mission file.

# Format
Format is `.keyword [ .keyword [ ] ]`.

| keyword     | description                  |
| ----------- | ---------------------------- |
| `.FASExxxx` | mission identifier (x = 0-9) |
| ...         |                              |
